# IT1214 - Student Grade Management System

## Project Purpose
This is a Java console-based application developed for a private educational institute to transition from manual paper-based and spreadsheet records to a streamlined digital system. The application leverages Object-Oriented Programming (OOP) concepts in Java to encapsulate student data and manage academic records efficiently. 

It acts as a functional system for teachers to digitalize student information, track performance, and automate basic administrative calculations.

---

## Features
The system provides a user-friendly menu-driven interface to perform the following operations:
1. *Add a New Student:* Store student details digitally including Student ID, Name, and Marks.
2. *Display All Students:* View all existing student records in a structured tabular format.
3. *Search Student by ID:* Instantly find a specific student's record using their unique Student ID.
4. *Calculate Average Marks:* Automatically compute and display the overall average mark of all registered students.

---

## Technical Concepts Used
* *Object-Oriented Programming (OOP):* Implements proper encapsulation by using private attributes in the Student class with public getters and setters.
* *Data Management:* Utilizes dynamic arrays (ArrayList) to manage and manipulate student objects at runtime.
* *Version Control:* Managed using Git and hosted on GitHub with an organized multi-commit development history.
